# Hi, I'm Huy 👋

Full-stack developer. I build and run the software behind my family's restaurant,
**Asian Le** in Prince Albert, SK: a POS, kitchen display, online ordering, a rewards
app, and the admin tools around them. It's all real production software that runs every
shift, and I built it on my own.

- 🔭 **Working on:** expanding the restaurant suite, and a self-hosted home server (Nextcloud on Ubuntu)
- 🌱 **Learning:** PostgreSQL and relational databases, and backend work beyond Firebase
- 🤝 **Open to:** full-stack web and mobile projects, especially ones with real users
- 💬 **Ask me about:** shipping React Native apps to the App Store, or running software for a real business

## 🍜 The Asian Le suite

Web, iOS and Android apps sharing one Firebase project, with each restaurant's data kept
separate under its own business.

| Project | What it is | Stack |
|---|---|---|
| [asian-le-pos](https://github.com/huybuivuanh/asian-le-pos) | Point of sale: dine-in tables, take-out, split bills, kitchen printing, rewards, customer-facing display | Expo, React Native, Firebase |
| [asian-le-kds](https://github.com/huybuivuanh/asian-le-kds) | Kitchen display that tracks every dine-in order in real time | Expo, Firebase |
| [asian-le-website](https://github.com/huybuivuanh/asian-le-website) | [asianle.ca](https://www.asianle.ca): menu, online ordering, reservations, rewards at checkout | Next.js, Tailwind, Firebase |
| [asian-le-orders](https://github.com/huybuivuanh/asian-le-orders) | Tablet app the staff use to accept, print and complete online orders | Expo, Firebase |
| [asian-le-rewards](https://github.com/huybuivuanh/asian-le-rewards) | Customer loyalty app: points, QR code, history | Expo, Cloud Functions |
| [asian-le-pos-admin](https://github.com/huybuivuanh/asian-le-pos-admin) | Back office for the POS: menu, tables, customers, staff, rewards members | Next.js, Radix UI |
| [asian-le-website-admin](https://github.com/huybuivuanh/asian-le-website-admin) | Website CMS, with automated phone calls, SMS and email for online orders | Next.js, Cloud Functions, Twilio |
| [asian-le-gift-card](https://github.com/huybuivuanh/asian-le-gift-card) / [admin](https://github.com/huybuivuanh/asian-le-gift-card-admin) | Gift cards with QR codes and balance tracking | Expo, Firebase |
| [print-server](https://github.com/huybuivuanh/print-server) / [orders](https://github.com/huybuivuanh/print-server-orders) | Node services that print kitchen tickets and receipts on thermal printers | Node.js, Express |
| [cash-register](https://github.com/huybuivuanh/cash-register) | Web cash register with X / Z reports, replacing an old physical one | Next.js, Firebase |
